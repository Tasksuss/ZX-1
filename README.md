# ZX-1

Repository for the Year 3 Project at the Department of Bioengineering, Imperial College London.

## Repository Structure

- `data_acquisition/`
  MATLAB scripts for serial logging and controlled data collection.
- `signal_analysis/`
  MATLAB scripts for demodulation, signal inspection, plotting, ICA, and map-position analysis.
- `imaging_analysis/`
  Notebooks and scripts for throat-image/video analysis, dimensionality reduction, and clip-level correlation analysis.
- `ml_experiments/`
  Machine-learning notebooks for model development and classification experiments.
- `pre_research/`
  Archived pre-research package containing the `PCA_LDA_pipeline` and `Simulation_pipeline` workflows.
- `docs/`
  Supporting PDFs, highlights, and mind maps used during project development.

## Notes

The repository is organized by workflow stage rather than by file type so that acquisition, signal processing, imaging analysis, modeling, and pre-research code remain clearly separated.
